= Aerie — User Quickstart
:toc: preamble

Get up and running in 60 seconds.

== Prerequisites

* Git 2.40+ and curl — nothing else; `./setup.sh` installs `just` and
  the rest of the toolchain for you (no sudo).

== Install

[source,bash]
----
git clone https://github.com/hyperpolymath/aerie
cd aerie
./setup.sh     # installs just + pinned Zig if missing, then checks the
               # toolchain with just doctor
just heal      # re-attempt automatic repair of anything doctor flagged
----

== First Run

[source,bash]
----
just tour      # guided project tour
just help-me   # see common workflows
----

== Get Help

* `just help-me` — common workflows
* `just doctor` — diagnose toolchain issues
* https://github.com/hyperpolymath/aerie/issues — report bugs
