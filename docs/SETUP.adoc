= Aerie — Setup (Four Approaches)
:toc: preamble

Everything you need to build, test, and run Aerie, four ways. The
Justfile is the single source of truth for commands; the other three
approaches are routes into it.

== Prerequisites (all approaches)

* **Zig 0.15.2+** — the gateway and FFI are Zig (estate law: API = Zig,
  FFI = Zig, ABI = Idris2).
* **just** — the estate task runner (no Makefiles).
* **Podman** (or any OCI runtime) — for the containerised stack.
* Optional: Rust (tracked-drift crate only — do not extend), Idris2
  (ABI + proven-tests suite), Guix (reproducible environment).

mise (`.mise.toml`) and Guix (`guix.scm`) both pin the toolchain if you
prefer managed versions: `mise install` or `guix shell -m guix.scm`.

== Approach 1 — AI-assisted

Give your agent exactly this prompt:

----
Read aerie_chora.deed, .claude/CLAUDE.md, and docs/SETUP.adoc in this
repository, then set it up: install missing tools with 'just heal',
verify the toolchain with 'just doctor', build with 'just build', and
run the test suite with 'just test'. Do not build, extend, or migrate
to src/api/rust (tracked drift). Report any gate that fails.
----

The deed (`aerie_chora.deed`) is the universal AI entry point: it names
the canonical locations, the architectural law, and the banned languages.

== Approach 2 — Raw (manual)

----
git clone <repo-url> aerie && cd aerie

# 1. Toolchain
#    Zig 0.15.2+ (ziglang.org or 'mise install'), just, podman

# 2. Build the gateway (debug, then release)
zig build
zig build -Doptimize=ReleaseSafe

# 3. Run the unit tests that live inside the build graph
zig build test

# 4. Run the full stack (gateway + librespeed + smokeping + hyperglass + redis)
podman compose -f compose.yml up

# 5. Verify: gateway answers on :4000 (REST+GraphQL) and :4001 (gRPC)
----

== Approach 3 — Just

----
./setup.sh          # platform detection + installs just if missing
just doctor         # toolchain health check (fails with a repair hint)
just heal           # attempts automatic repair of missing tools
just build          # zig build (debug)
just build-release  # zig build -Doptimize=ReleaseSafe
just test           # in-tree suites (zig, idris2, rust) + submodule suites
just lint           # shellcheck + typos
just clean          # remove build artefacts
just install        # install the gateway binary (PREFIX overridable)
----

See `just --list` for the full recipe matrix, and `just man` for the
generated man page.

== Approach 4 — Standards launcher

----
./aerie-launcher.sh
----

The launcher is generated by `launch-scaffolder` from
`aerie.launcher.a2ml` (do not hand-edit the script). It implements the
estate launcher standard: keep-open lifecycle, desktop-tools resolution
ladder, and soft-attach. Pass `--help` for the full argument surface
(also documented in `docs/man/aerie.1`).

== Environment variables

The gateway reads configuration from the environment (no secrets in
repo): `LIBRESPEED_URL`, `HYPERGLASS_URL`, `SMOKEPING_URL`, `REDIS_URL`,
`AERIE_API_KEY` (policy gate), `AERIE_HTTP_PORT` (4000), `AERIE_GRPC_PORT`
(4001). See `src/api/zig/main.zig` for the authoritative list.
