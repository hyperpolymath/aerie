= Aerie API — V-lang Implementation SIDELINED
:toc:

== Status

The V-lang implementation of the Aerie API service (`src/api/v/`) is *sidelined*
as of 2026-04-12 following the estate-wide V-lang ban (2026-04-10).

V-lang is banned across all hyperpolymath repositories. See
link:https://github.com/hyperpolymath/standards/blob/main/VLANG-BAN.adoc[VLANG-BAN.adoc]
for rationale and migration guidance.

== Build

```bash
zig build              # produces zig-out/bin/aerie-gateway
zig build run          # build and run
zig build test         # unit tests
```

The root `build.zig` was added 2026-04-17 for the Zig gateway binary.
The `ffi/zig/build.zig` (pre-existing) remains for the FFI shared library.

== Note on V-grpc Dependency

The `v.mod` listed `v_grpc` as a dependency. The Zig port implements the
same Phase 1 length-prefixed JSON protocol over TCP (no `v_grpc` equivalent
needed). A full HTTP/2 gRPC stack is Phase 2.

The V-lang source is retained in-tree for reference but MUST NOT be compiled,
deployed, or extended.
