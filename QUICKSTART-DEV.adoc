= Aerie — Developer Quickstart
:toc: preamble

Clone, build, test, contribute.

== Prerequisites

* Git 2.40+ and curl — nothing else; `./setup.sh` installs the rest
* `just doctor` output tells you the language-specific state afterwards

== Setup

[source,bash]
----
git clone https://github.com/hyperpolymath/aerie
cd aerie
./setup.sh     # zero-prerequisite: installs just + pinned Zig (curl only),
               # then runs just doctor. Safe to re-run.
just doctor    # re-verify the toolchain any time
just heal      # re-attempt automatic repair of anything doctor flags
----

== Development Workflow

[source,bash]
----
just tour      # understand the codebase
just help-me   # see available commands
----

== Before Committing

[source,bash]
----
just assail    # run panic-attacker security scan
----
