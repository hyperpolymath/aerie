== What we affirm, and how it was checked

1. **The repo deed conforms to the normative DEED ABNF (v1.0.0).**
   Checked by running the standards' own validator in this session:
   `python3 standards/1-formats/deed/tools/deed_lint.py aerie_chora.deed`
   → `OK aerie_chora.deed`, exit 0. The deed is the universal AI entry point
   (standards#837 one-deed-per-repo doctrine).

2. **Every gitlink in the repository has a `.gitmodules` mapping.**
   Checked by `git submodule status`: before this audit it fataled with
   `no submodule mapping found in .gitmodules for path 'network/bgp-backbone-lab'`;
   after the fix it lists all eight submodules (root bgp-backbone-lab,
   qubes-sdp, six network/*) without error. All eight target repositories
   were confirmed to exist in the estate via the GitHub API.

3. **No estate-banned language surface remains outside tracked, documented
   drift.**
   Checked by file census (`find` + extension audit): Deno config deleted
   (`examples/web-project-deno.json`, banned 2026-09-22); no `.ts`/`.res`/
   `.v`/`flake.nix` tracked; `src/stale/hyperglass` (vendored upstream with
   legacy artifacts) is explicitly marked stale and recorded in the roadmap
   rather than silently carried. `src/api/rust/` is *retained on purpose*:
   it is tracked drift named as such in `.claude/CLAUDE.md`, `ARCHITECTURE.md`
   and the deed, with removal an owner decision.

4. **The licence is MPL-2.0 (code) / CC-BY-SA-4.0 (prose docs) and aerie is
   not in the PMPL register.**
   Checked against `hyperpolymath/standards` 3-practice/LICENCE-POLICY.adoc
   (register: palimpsest-license, palimpsest-plasma, consent-aware-web,
   insolvency-tycoon, sim-public-relations) and against the tracked
   `LICENSE` (MPL-2.0 full text) + `LICENSES/` dual texts. The README's
   former "PMPL-1.0" badge was drift; it now reads MPL-2.0/CC-BY-SA-4.0.

5. **CI wrapper workflows are SHA-pinned to the estate reusable set.**
   Checked by inspection of `.github/workflows/` (12 pre-existing wrappers +
   4 added this pass); every `uses:` of a third-party action carries a full
   commit SHA with a version comment (estate pattern, PR #83).

6. **What we do NOT affirm:** that the project builds or that its tests
   pass, as of this stamp. No compiler or interpreter for any project
   language was available in the audit sandbox, and the network allowlist
   excluded every toolchain CDN. That is a gap to close in CI
   (`validation.yml` and the existing gate workflows), not a claim to make.
